# 版本部署变更说明 v0.1.3

- 版本：`0.1.3`（`manifest.json` / `package.json` / `backend/Cargo.toml` 三处一致）
- 产物：`release/com.mjj3610.mail-0.1.3-windows-x64.dbxp`（13 条目，2.34 MB）
- 变更性质：**布局缺陷 + 同步范围修复**，无数据结构变更，可直接覆盖安装

## 1. 修复：长邮件正文无法滚动

现场：打开一封内容较长的营销邮件（固定 700px 模板），正文既滚不动，左右还被裁掉。

根因两条，互相叠加：

**1.1 网格行高被内容撑开，滚动容器没有可滚空间**

`.app` 是 `display: grid; height: 100%`，但没给行高。隐式 `auto` 行按内容计算，而 grid 子项
`.reader-pane` 的 `min-height` 默认是 `auto`（不能收缩到内容以下），于是长正文把阅读区顶到 1638px，
`.reader-scroll` 的 `clientHeight` 直接等于 `scrollHeight`（1574 = 1574）——容器自己被撑高了，自然「滚不动」。
列表区 `.list-pane` 同样问题（会话很多时会复现）。

修复（`src/style.css`）：

- `.app { grid-template-rows: minmax(0, 1fr) }`，行高锁死为容器高度；
- `.list-pane`、`.reader-pane` 补 `min-height: 0`，允许内部滚动容器收缩。

**1.2 邮件自带的 `body{height:100%;overflow:hidden}` 被收敛到正文容器**

v0.1.2 引入 `<style>` 作用域收敛后，邮件里写给整页的 `body{...}` 会映射到 `.mail-html`。
营销模板普遍带 `overflow:hidden`，落到正文容器上就变成「裁掉溢出」：700px 宽的内容被左右切掉，
左侧部分根本无法滚动到。

修复（`src/lib/html.ts`）：当规则的作用域正好落在容器本身（来自 `html` / `body` / `:root`）时，
摘掉 `height` / `min-height` / `max-height` / `overflow*` / `position` / `display` 这些骨架属性，
字号、颜色、行高、背景等照旧保留。另外 `.mail-html > *` 加 `max-width: 100%`，
让写死 700px 的外层容器在窄窗口下收得回来。

## 2. 修复：非主收件箱无法同步

现场：侧栏自定义文件夹（`12306`、`加油票`、`通行费` 等）点进去永远空白，提示「新的邮件会在同步后出现在这里」。

根因：同步范围默认 `primary`，只覆盖收件箱/已发送/草稿/存档；自定义文件夹既不在范围内，
也没有任何手动入口——界面只能显示空。

修复：

| 位置 | 改动 |
| --- | --- |
| `stores/mail.ts` | 新增 `syncFolderIfNeeded`：进入文件夹时若 `uidValidity = 0`（从未同步过）就自动拉一次；同步过或服务器上本来为空则不再触发。`sync()` 补了错误捕获（此前失败会静默变成 unhandled rejection） |
| 列表空状态 | 新增「同步此文件夹」按钮，明确入口 |
| 列表头部刷新按钮 | 打开具体文件夹时只同步该文件夹（`mailboxId`），否则仍按设置同步 |
| `backend/src/main.rs` | `sync/now` 只给了 `mailboxId` 时，从该文件夹反查所属账户——此前会拿这个 id 去跑每一个账户（多余登录与网络开销） |
| 设置文案 | 明确「主要文件夹（收件箱、已发送、草稿、存档）」/「全部文件夹（含自定义文件夹，不含垃圾/已删除）」 |

顺带修两处会误导的显示：

- **同角色的多个文件夹同名**：`垃圾邮件` 与 `广告邮件` 都判为 junk，侧栏会出现两条一模一样的「垃圾邮件」。
  现在第一个用角色名，重复的用服务器上的真实名字（`垃圾邮件` / `广告邮件`）。列表标题同理。
- **头部未读数用错来源**：此前无论打开哪个文件夹都显示全局收件箱未读（打开「订阅邮件」却显示 11 封未读）。
  现在打开具体文件夹时用该文件夹的未读数。

## 4. 升级步骤

1. 关闭邮件工作台页面；
2. 覆盖安装 `release/com.mjj3610.mail-0.1.3-windows-x64.dbxp`；
3. 设置里确认版本为 **0.1.3**；
4. 打开之前空白的自定义文件夹，会自动同步一次；也可点「同步此文件夹」或头部刷新。

数据无需迁移；表结构与 `0.1.2` 一致。

## 5. 回滚

重新安装 `release/com.mjj3610.mail-0.1.2-windows-x64.dbxp`。
