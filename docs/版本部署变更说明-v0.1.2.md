# 版本部署变更说明 v0.1.2

- 版本：`0.1.2`（`manifest.json` / `package.json` / `backend/Cargo.toml` 三处一致）
- 产物：`release/com.mjj3610.mail-0.1.2-windows-x64.dbxp`（13 条目，2.34 MB）
- 变更性质：**显示缺陷修复**，无接口与数据结构变更，可直接覆盖安装

## 1. 修复：被拦截的远程图片显示成「碎图」

现场：正文里所有远程图片都渲染成「碎图标 + alt 文字」（`GitHub`、`b`、`validat e`），布局被撑散。

根因：拦截实现是 `image.removeAttribute('src')`。没有 `src` 的 `<img>` Chromium 会画成破碎图标并**显示 alt 文字**，
而占位框的虚线/斜纹样式又被文本撑变形。

修复（`src/lib/html.ts`）：

| 做法 | 说明 |
| --- | --- |
| 透明像素顶位 | 拦截时把 `src` 换成 1×1 透明 GIF（本地 data URL，不产生请求），不再出现碎图与 alt |
| 保留原始尺寸 | 按 `width`/`height` 属性画占位框；只有宽度时按 46×26 条；只有 `style="width:100%"` 时用 `aspect-ratio: 16/9` 推高度 |
| 跟踪像素隐藏 | 声明尺寸 ≤ 2px 的图判定为跟踪像素，直接 `display:none`，不再留下莫名的小方块（截图里那个 `b`） |
| 点击即加载 | 点占位框可放开全部图片（图片本身是链接时让给链接跳转） |
| 还原尺寸 | 图片真正取回后撤掉占位时写入的宽高，避免真图被压扁 |

顺带补上同一类遗漏：CSS `background-image: url(http…)` 与老式 `background="…"` 属性同样先拦后取（此前它们既不显示也不计入拦截数）；
后端没转换成功的 `cid:` 内嵌图不再画碎图。

## 2. 修复：邮件排版被 Tailwind preflight 抹平

`@import "tailwindcss"` 的 preflight 对 `*` 做了 `margin/padding/border` 清零，并把 `h1~h6` 变成 `font-size:inherit`、
列表去掉 `list-style`、`img` 改成 `display:block`。邮件正文恰恰依赖这些默认样式，于是表现为：

- 段落全部粘在一起（`<p>` 没有间距）；
- 无序/有序列表**没有圆点数字**，且顶格；
- 标题与正文同号，看不到层级；
- 表格 `border="1"` 的边框被 `border: 0 solid` 抹掉；
- `<hr>` 不可见；行内小图标各占一行（`display:block`）。

修复：在 `src/style.css` 的 `.mail-html` 作用域内逐项还原（字号阶梯、段落间距、`disc/decimal/lower-alpha` 列表、
嵌套列表 marker、`hr`、`code/pre`、`table[border]` 边框、`th` 加粗左对齐、`img { display:inline-block }`）。

## 3. 新增：支持邮件自带 `<style>`（带作用域收敛）

此前 DOMPurify 会把 `<style>` 连同内容一起丢弃（它在 `FORBID_CONTENTS` 里），凡是把排版写在 `<style>` 的邮件都会退化成无样式文本。

现在改为「先整段抽出 → 自己收敛作用域 → 以 `textContent` 注入正文容器」：

- 选择器统一加 `.mail-html` 前缀，`html` / `body` / `:root` 直接映射到容器本身；`@media` / `@supports` / `@layer` 递归处理；
- 去掉 `@import`（远程样式表等于跟踪信标）；
- `position: fixed | sticky` 落回 `static`，避免覆盖层盖住界面；
- 注入走 `textContent`，邮件里的 `</style><script>` 之类的字符串无法变成标记。

深色模式下再摘掉 CSS 里写死的 `color` / `background` / `background-color` / `border-color`（与既有的 `adaptForDark` 一致），
否则深色文字落在深色底上会看不见；容器背景压回透明，边框统一改用主题分隔色。

## 5. 升级步骤

1. 关闭邮件工作台页面（避免占用 `backend.exe`）；
2. 覆盖安装 `release/com.mjj3610.mail-0.1.2-windows-x64.dbxp`；
3. 重新打开，设置里确认版本为 **0.1.2**；
4. 打开任意一封带图邮件，确认图片位置显示为斜纹占位框（不再是碎图标 + 文字），点「显示图片」后正常加载。

数据无需迁移，表结构与 `0.1.1` 一致。

## 6. 回滚

重新安装 `release/com.mjj3610.mail-0.1.1-windows-x64.dbxp` 即可，本地数据库兼容。
